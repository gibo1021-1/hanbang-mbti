# 나의 한방 건강 유형 테스트

한약사가 만든 1분 생활 유형 테스트예요. 질문 12개에 답하면 寒熱·虛實 두 축으로 4가지 유형 중 하나가 나오고, 맞는 한방차와 생활 처방, 함께 먹을 때 주의할 점을 알려줘요.

| 유형 | 이름 | 한 줄 설명 |
|---|---|---|
| 寒虛 | 웅크린 화로형 | 불씨는 있는데 장작이 모자란 몸 |
| 寒滯 | 고인 연못형 | 물이 잘 돌지 않아 무거운 몸 |
| 熱虛 | 마른 잎형 | 촉촉함이 부족해 쉽게 달아오르는 몸 |
| 熱實 | 끓는 주전자형 | 열이 위로 차올라 김이 나는 몸 |

## 유형별 바로가기 링크

주소 끝에 `#유형코드`를 붙이면 해당 유형 결과가 바로 열려요. 스레드나 블로그 글에 유형별로 링크를 걸 때 쓰면 좋아요.

- `#gaon` 웅크린 화로형
- `#jeong` 고인 연못형
- `#maru` 마른 잎형
- `#kkeul` 끓는 주전자형

## 고치는 법

모든 내용은 `index.html` 한 파일에 있어요.

- 질문 문구: `const QUESTIONS` 부분
- 유형 설명·추천 차·주의사항: `const TYPES` 부분
- 스레드 주소: `const THREADS` 부분

## 안내
